# 🟢 Escape The Matrix

A 3D first-person Matrix-themed escape room game built with React and Three.js.

All code and documentation live in the app directory — see the
[full README](matrix-escape/README.md) for gameplay, controls, development,
testing, and deployment instructions.

## Quick Start

```bash
cd matrix-escape && npm install && npm run dev
```

Then open `http://localhost:5173`.
